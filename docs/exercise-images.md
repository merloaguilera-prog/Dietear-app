# Primera colección de ejercicios — 25/10/2026

Ocho tarjetas numeradas sustituyen los cuatro accesos sin fotografía del módulo
«Pasos y actividad». Cada tarjeta usa una fotografía diferente, almacenada en el
repositorio en WebP. Las fuentes, autores y licencias se muestran en la propia
colección y se conservan en `lib/exercise-catalog.js`.

Las fotografías son representativas de cada categoría, no instrucciones de cada
movimiento ni avales de las personas retratadas. La lista contiene nombres de
movimientos, sin series, intensidad prescrita ni afirmaciones de idoneidad clínica.
«Registrar minutos realizados» selecciona el tipo correspondiente en el registro
existente; no inventa actividad completada ni cambia datos del usuario por abrir
una tarjeta. El usuario elige y guarda sus minutos.

Validación: numeración, ausencia de fotografías/movimientos repetidos, archivos
locales WebP, tamaño máximo de cada imagen, créditos y compatibilidad con los tipos
del registro. No se modifica el paquete Android ni la lista de probadores.

Quedan fuera de esta primera colección las categorías pendientes del borrador #36
(pared, escalón, cama y otras adaptaciones). Las imágenes de órganos se revisan
por separado, después de esta colección.
